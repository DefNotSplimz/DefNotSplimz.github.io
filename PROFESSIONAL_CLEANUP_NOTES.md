# Datum Prototyping — Professional Cleanup

This pass intentionally avoids a redesign. It refines the approved site through hierarchy, spacing and interaction polish.

## Changes
- More consistent desktop section rhythm and spacing.
- Removed floating/lifting card interactions; retained restrained border/image feedback.
- Improved service, project and process card proportions.
- Re-composed the About section so copy, portrait and brand statement read as one unit.
- Refined the quote treatment without changing the approved statement.
- Reworked Contact into a clearer project-intake hierarchy while retaining the existing clipboard workflow.
- Improved form labels, fields, file picker, status copy area and CTA alignment.
- Improved tablet/mobile spacing for About and Contact.
- Matched project viewer interactions to the calmer homepage behaviour.
- No shadows added. No brand/logo changes. No project/document data changed.
