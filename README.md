# Datum Prototyping V5.4.1 — Refined Flow

Baseret på V5.4 / CONTROLLED IMPACT.

## Ændringer
- Hjemmesidens hero og godkendte indhold er bevaret.
- Nye kontrollerede grafiske overgange mellem afsnit (HTML/CSS med diskret JS-forbedring).
- 404 er redesignet med et stort 404-symbol, dramatisk fotografi og fungerende tilbage-links.
- Privatliv er redesignet med en selvstændig hero, tydelig informationsstruktur og det eksisterende privatlivsindhold uden nye løfter om webhotellet.
- Ingen nye eksterne scripts, tracking, cookies, formularer eller downloadede skrifttyper.

## Upload
Udpak ZIP, og upload indholdet af mappen til domænets webrod (ikke overmappen alene). Kontrollér at .htaccess følger med, hvis serveren bruger Apache/LiteSpeed. På andre hosts kan 404-konfiguration kræve en særskilt indstilling.

## Test
Se docs/QA_V5.4.1.md. Test på den offentlige hosting: HTTP 404-status for ugyldige stier, HTTPS, sitemap og delingspreview.
