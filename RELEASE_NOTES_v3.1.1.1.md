# Datum Prototyping v3.1.1.1 — Section Label Cleanup

The numeric `01 /`, `02 /`, `03 /` section-prefix system has been removed from the public-facing website and document section labels.

## Changed
- Homepage section eyebrows no longer show numbered prefixes.
- Contact / Project Brief detail labels no longer show numbered prefixes.
- Project-case category labels no longer use `01 /`, `02 /`, `03 /`.
- FAI document section chips no longer use the numbered-slash prefix style.
- Existing content, navigation, brand v3.1 assets and functionality are otherwise unchanged.
