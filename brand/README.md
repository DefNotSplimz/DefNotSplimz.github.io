# Datum Prototyping — brand 01

Ny separat brandpakke. Eksisterende hjemmeside og gamle originaler er bevaret.

- logos/: vandret og stablet logo, SVG med tekst som kurver samt transparent PNG. Farve til mørk/lys baggrund og sort/hvid.
- symbols/: eksisterende genkendeligt finmekanikmærke i samme farver.
- graphics/: ny datummarkering samt linje. Datummarkeringen supplerer logoet.
- web/: favicon, Apple/PWA-ikoner, manifest, farvevariabler og eksempel på HTML-integration. Favicon bruger den enkle datummarkering for læsbarhed i lille størrelse.
- social/: OG 1200×630 og avatar 1024×1024.
- email/: PNG, SVG og HTML. Fulde navn kun her. Indsæt PNG i mailprogrammets signatur; lokale billedstier i HTML skal erstattes med en tilgængelig URL eller indlejres af mailprogrammet.
- documents/: redigerbare HTML-designskabeloner til FAI og setup sheet. Ingen automatiske toleranceberegninger, dokumentlagring eller standardcertificering. Redigér kilden for permanent lagring; felter kan også udfyldes midlertidigt i browseren og printes. Eksisterende rapportdata er ikke ændret.
- workwear/: vektororiginaler til dialog med trykkeri.
- presentation/: godkendt AI-koncept, kun reference.

Åbn brand-guide.html for visuelt overblik.

Typografi: Arial/Helvetica til kommunikation, Consolas/Courier New til tekniske data; fonte medfølger ikke. Logoets tekst er kurver og kræver ingen font. Bevar proportioner og mindst 1/4 symbolhøjde fri plads rundt om logoet. Ved meget lille brug vælges datummarkeringen; fuldt logo anbefales mindst 180 px på skærm.

Orange #FB7949, varm hvid #ECECE5, koksgrå #181A1A, grafit #343735. Orange bruges som accent, ikke lille tekst på hvidt. Dokumenter printes på hvidt. Ingen gradienter eller effekter på logoet.

Tryk: SVG er RGB-vektororiginaler, ikke maskinspecifikke broderifiler. Aftal størrelse, stregtykkelse, materiale og fysisk farveprøve med producenten. Fine logodetaljer kan kræve en særskilt broderiversion.

Hjemmesiden bruger Glen; fuldt navn er kun til mailsignaturen. Pakken er ikke automatisk publiceret.
